# Hi, I'm Josh

Investigative reporter and 2023–24 Fulbright Journalism Fellow based in Berlin, Germany. I cover extremism, disinformation, and technology — work that's appeared in WIRED, Mother Jones, Deutsche Welle, Die Zeit, The Daily Beast, NPR, and more.

I'm increasingly using AI and computational methods — OSINT, LLMs, lightweight scripting — to make reporting faster and more rigorous. I'm also an English major by training, not a computer scientist, so everything I build here is meant to be usable by journalists who don't code: clear instructions, no unexplained jargon, nothing that requires a CS degree to run. The tools should handle the tedious part so we can get back to the fun part — writing and reporting.

This page collects two kinds of things:

**🛠 Tools** — small, free, journalist-facing utilities that solve a real problem I've hit on deadline.
- [`transcribe`](https://github.com/joshdaxelrod/transcribe) — turns a folder of interview recordings into searchable, timestamped transcripts, entirely on your own computer. No subscription, no uploads.
- More coming: a Telegram channel-monitoring tool for tracking extremist and disinformation networks.

**📓 Story walkthroughs** — case studies on stories where OSINT or code work did real reporting work, not just a portfolio flex.
- Coming soon.
